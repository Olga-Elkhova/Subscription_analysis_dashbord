# Subscription_analysis_dashbord

# Анализ платежей донаторов благотворительного фонда

## О проекте

**Цель**: Провести комплексный анализ данных о пожертвованиях для выявления факторов удержания донаторов, оценки эффективности регулярных подписок и разработки стратегий по увеличению объема пожертвований.

**Основные задачи**:
*   Оценка текущих бизнес-показателей фонда.
*   Сегментация донаторов (RFM-анализ).
*   Анализ когорт и жизненного цикла донаторов.
*   Анализ подписок и построение кривой выживаемости (Survival Analysis).
*   Разработка практических рекомендаций по повышению эффективности работы с донаторами.

## Результаты

Ключевые выводы и рекомендации представлены в файле `analysis.ipynb` и кратко изложены в разделе **Итоговые выводы** ниже.

**Дашборд**: Интерактивный дашборд для визуализации ключевых показателей создан с помощью Streamlit и доступен в файле `dashboard.py`.

## Как воспроизвести анализ

Для запуска проекта выполните следующие шаги.

### 1. Установка зависимостей

Перед запуском убедитесь, что у вас установлены все необходимые библиотеки. Выполните в терминале:

```pip install -r requirements.txt```

### 2. Запуск анализа (Jupyter Notebook)

```jupyter notebook analysis.ipynb```

### 3. Запуск дашборда (Streamlit)

```streamlit run dashboard.py```

# Итоговые выводы и рекомендации

На основе проведенного анализа были сформулированы следующие практические рекомендации для фонда:

**Увеличение регулярных пожертвований:**

- Упростить процесс подписки: Сократить число шагов для оформления регулярного платежа до 1-2 кликов.

- Предложить гибкие варианты: Внедрить возможность смены даты, суммы и способа оплаты подписки.

- Стимулировать переход: Предложить промокод или небольшой бонус (например, именной сертификат) для донаторов, переходящих с разового на регулярный платеж.

**Повышение удержания донаторов:**

- Сфокусироваться на ранних этапах: Запустить welcome-кампанию в первый месяц, включая благодарственное письмо и отчет о первых результатах использования пожертвования.

- Информировать о влиянии: Регулярно отправлять персонализированные письма о том, как именно помощь донатора изменила чью-то жизнь.

- Оживить "уходящие" сегменты: Для донаторов из групп "At Risk" и "About to Churn" создать специальные re-engagement-кампании, выясняя причины снижения активности.

**Увеличение средней продолжительности подписки:**

- Ввести программу лояльности: Создать систему накопительных бонусов или признания для донаторов, поддерживающих фонд более 3, 6 и 12 месяцев.

- Разработать контент-стратегию: Ежемесячно предоставлять донаторам эксклюзивный контент: видео-отчеты, интервью с подопечными, "закулисные" материалы.

**Рост долгосрочной ценности (LTV):**

- Сфокусировать усилия на "Супер-донаторах": Создать сообщество ключевых донаторов (амбассадоров), приглашать их на специальные мероприятия, привлекать к формированию стратегии фонда.

- Внедрить систему персонализации: Использовать данные о предпочтениях донаторов для предложения целевых проектов и способов помощи.
